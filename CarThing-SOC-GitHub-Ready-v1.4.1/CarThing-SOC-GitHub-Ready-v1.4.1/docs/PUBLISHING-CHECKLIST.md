# Before clicking Publish

- [ ] Run fresh local `npm test` and `npm run build` from `deskthing-app/` and API tests from `ubuntu-backend/`.
- [ ] Confirm the app and AI backend run together on the actual device, including knob navigation and a completed on-demand request.
- [ ] Rotate any API key exposed in chats/screenshots. Ensure Windows local `config.json` and backend `.env` are not in the GitHub repo.
- [ ] Review screenshots for user names, tailnet hostname, Tailscale IP, security logs, device IDs, private URLs and file paths.
- [ ] Decide whether to add an open-source license; no license is included by default.
- [ ] Create a new GitHub repository named `CarThing-SOC-AI`; upload the *contents* of this folder, not the ZIP as a single file.
- [ ] Add 3–4 redacted screenshots and/or a short demo video, then copy the repository URL to the LinkedIn draft.
- [ ] Use the LinkedIn draft, describe AI output as provisional, and don't claim autonomous threat remediation or production deployment.
